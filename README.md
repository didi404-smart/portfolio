## 3. MathTrainer — десктоп-приложение для тренировки математики

**Что сделано:**
- Разработано десктоп-приложение на Python с графическим интерфейсом PySide6 для тренировки базовой математики детьми дошкольного и младшего школьного возраста.

- Реализованы пять тематических разделов: сложение, вычитание, умножение, деление и уравнения.

- Добавлена система уровней сложности с разными диапазонами чисел и типами заданий.

- Реализованы два режима работы: свободная подготовка и тестирование с ограниченным количеством вопросов.

- Созданы генераторы математических задач с использованием модуля random.

- Добавлены проверка ответов, обратная связь через интерфейс, отображение прогресса и итогового результата теста.

- Реализована обработка клавиатурного ввода для управления тренировкой.

- Написаны unit-тесты на pytest для проверки генераторов задач с использованием unittest.mock и подмены случайных значений.

**Стек:** Python 3.14, pytest, unittest.mock, random, Poetry, Git.

**Основные возможности:**
- Пять тем: сложение, вычитание, умножение, деление и уравнения.

- Несколько уровней сложности для каждой темы.

- Режим «Подготовка» — неограниченное количество примеров с возможностью повторного ввода ответа и просмотра правильного решения.

- Режим «Тест» — от 1 до 100 вопросов, одна попытка на вопрос, отображение прогресса и итогового результата.

- Бесконечная генерация новых примеров в режиме подготовки.

- Повторное прохождение теста с теми же настройками.

**Ссылки:**
```
Репозиторий: https://github.com/didi404-smart/MathTrainer
```
Как запустить:
```
git clone https://github.com/didi404-smart/MathTrainer.git
cd MathTrainer

pip install poetry
poetry install

poetry run python -m src.MathTrainer.ui.app
```
Запуск тестов:
```
poetry run pytest
```
Запуск тестов с отчётом о покрытии, включая ветвления:
```
poetry run pytest --cov=src.MathTrainer --cov-branch --cov-report=term-missing
```
Тесты проверяют генераторы математических задач. Для получения детерминированных результатов случайные значения random.randint и random.choice подменяются с помощью фикстур из tests/conftest.py.

Архитектура проекта:
```
    core/ — модель математической задачи.

    generators/ — отдельные модули генерации задач для каждой темы.

    ui/ — графический интерфейс, навигация, режимы подготовки и тестирования.

    tests/ — автоматические тесты генераторов.
```
Архитектура позволяет добавлять новые темы и варианты заданий без существенного изменения существующего интерфейса.
